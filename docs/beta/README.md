# Beta

CFW Card Studio is in a small beta for handhelds that use ArkOS-style cards, including the R36S. About 20 people from r/R36S are in this round. Each tester gets a free key.

## Join

Aaron is inviting the testers for this round. If you were invited, start with the [tester checklist](TESTER_CHECKLIST.md). A wider test will wait until the reports from this round are in. There is no date for that yet.

## Your free key

Aaron will send you a key. In the app, choose **View license**, then **Enter key**, and paste the key. Backup, restore, the card tests, guided setup, and **Save support file** also run before the key is entered.

## What to send

1. Follow the [tester checklist](TESTER_CHECKLIST.md).
2. File a [hardware report](https://github.com/toilmonkey0-cyber/cfw-zero-touch/issues/new?template=beta-hardware-report.yml) when you finish the tests you can run.
3. File a [beta bug](https://github.com/toilmonkey0-cyber/cfw-zero-touch/issues/new?template=beta-bug.yml) when something goes wrong.

A useful report names the device, the board, and the card, marks pass or fail for each checklist test, includes the stock-card fingerprint when you could collect it, and has the support zip attached to the issue. Leave game files and the backup image off GitHub.

Critical bugs are data loss, a card that will not boot and cannot be restored from the backup, or the wrong disk offered or written. This round stays small while any critical bug is still open, and until at least 10 successful hardware reports cover at least 3 device types.
